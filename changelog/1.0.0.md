# NerdBackpacks 1.0.0

**Minecraft:** 1.20.1  
**Loader:** Forge 47+  
**Release type:** Initial release

---

## Highlights

- Five tiered backpacks (27 → 99 slots, +18 per upgrade)
- Vanilla-style GUI with scrolling on larger tiers
- Placeable backpacks with model-fitted hitboxes
- Wearable on the vanilla chestplate slot
- Optional **Curios** support (`back` / `chest`)
- Optional **JEI**, **Jade**, and **Mouse Tweaks** integrations

---

## Added

### Backpacks & crafting

- Added **Sack** crafting ingredient
- Added backpacks **Level I–V** (`mochila_1` … `mochila_5`)
  - Level I: 27 slots  
  - Level II: 45 slots  
  - Level III: 63 slots  
  - Level IV: 81 slots  
  - Level V: 99 slots  
- Added upgrade recipes that **preserve inventory NBT** when crafting the next tier
- Backpacks cannot be nested inside other backpacks

### Inventory GUI

- Vanilla chest-style interface
- Scrollbar + mouse wheel for tiers larger than 7 visible rows
- Middle-click sort: merge stacks, A→Z by item id, full stacks before leftovers (e.g. 65 → 64 + 1)
- Shift-click / quick-move across the full backpack (including scrolled-off slots)
- Locked hand / equipment slot while the GUI is open so items are not voided

### World interaction

- **Shift + right-click** to place a backpack
- Right-click placed backpack to open
- **Shift + right-click** placed backpack to pick up with contents intact
- Block drops and pick-block keep stored inventory

### Equipment & controls

- Equip on the vanilla **chestplate** slot
- Optional Curios: equip on **back** and **chest** slots
- At most **one** backpack worn at a time (chest or Curios, never both / never two Curios backpacks)
- Default keybind **B** opens the equipped backpack (remappable)
- Empty-hand right-click in air opens the worn backpack
- On-body rendering for chest and Curios equipment

### Collision

- Per-tier selection/collision shapes based on each backpack model AABB (not a full cube)

### Compatibility

- **JEI** (optional): backpack crafting recipes shown as crafting
- **Jade** (optional): placed backpack contents preview (hold Shift)
- **Curios** (optional): soft dependency for wear / render / open
- **Mouse Tweaks** (optional): GUI drag support; wheel tweak disabled in the backpack screen so scrolling works

### Localization

- English (`en_us`)
- Brazilian Portuguese (`pt_br`)

## Notes

- Worn pose (scale, offsets, rotation) can be tuned in code via `BackpackBodyPose` for pack maintainers.
- This is the first public feature set for **1.0.0**.
